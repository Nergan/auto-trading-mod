# Автоторговля

[English](README.md)

Чисто клиентский мод Fabric для Minecraft 26.3. Персонаж сам проходит маршрут: забирает предметы из входных контейнеров, торгует с выбранными жителями и относит результат в выходные контейнеры. Строка статуса на панели всегда на английском. Сообщения и экран настроек идут на языке игры.

## Загрузчики

| Minecraft | Загрузчик | В этом проекте |
| --- | --- | --- |
| 26.3 | Fabric | да |
| 26.3 | NeoForge | нет |
| 1.21.1 | Fabric / NeoForge | нет |

Серверной части нет. На выделенном сервере мод пропускается (`environment: client`), сервер при этом запускается.

Пуш в `main` обновляет одну страницу GitHub Release: [auto trading for minecraft 26.3 fabric](https://github.com/Nergan/auto-trading-mod/releases/tag/minecraft-26.3-fabric). Страницы на Modrinth нет. `all-jars.zip` на этой странице содержит все jar из таблицы.

| Файл | Обязателен | Что это |
| --- | --- | --- |
| `autotrading-fabric-26.3-1.0.0.jar` | да | сам мод |
| `fabric-api-0.162.0+26.3.jar` | да | [Fabric API](https://modrinth.com/mod/fabric-api) |
| `fabric-language-kotlin-1.14.2+kotlin.2.4.21.jar` | да | [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) |
| `cloth-config-fabric-26.3.159.jar` | да | [Cloth Config](https://modrinth.com/mod/cloth-config) |

`autotrading-fabric-26.3-1.0.0-sources.jar` в `mods` не кладут.

## Требования

- Minecraft 26.3
- Fabric Loader 0.19.5 или новее
- Java 25
- Fabric API `0.162.0+26.3`
- Fabric Language Kotlin `1.14.2+kotlin.2.4.21` или новее
- Cloth Config `26.3.159` (`cloth-config`)
- Mod Menu `21.0.0` необязателен. Он только открывает настройки. Без него мод работает с последним сохранённым `config/autotrading.json`.

## Установка

Положи `autotrading-fabric-26.3-1.0.0.jar` в `mods` экземпляра Fabric 26.3 рядом с Fabric API, Fabric Language Kotlin и Cloth Config. Mod Menu ставь, если нужен экран настроек.

## Как пользоваться

Панель начинается с `autotrading: disabled`. Нажми `T`, чтобы открыть чат: мышь освобождается, а панель остаётся поверх чата. Кнопки принимают клик только когда мышь свободна.

1. Нажми `set trading`. Статус станет `autotrading: setting input containers...`, вторая кнопка сменится на `cancel`. Под статусом счётчик показывает, сколько контейнеров уже запомнено.
2. ПКМ по каждому входному контейнеру, чтобы открылся его экран. Повторный клик по тому же счётчик не увеличивает. Постановка блока не считается, и свой инвентарь тоже не считается. В руке не должно быть блока. Затем `apply`.
3. Статус станет `autotrading: setting trade villagers...`. ПКМ по каждому жителю, затем `apply`. Окно торговли открывается как обычно.
4. Статус станет `autotrading: setting output containers...`. ПКМ по каждому выходному контейнеру, затем `apply`. Статус вернётся к `autotrading: disabled`, кнопка снова станет `set trading`.
5. `cancel` на любом из этих шагов сбрасывает черновик. Уже сохранённый маршрут остаётся. Пока вторая кнопка показывает `set trading`, `apply` ничего не делает. Она также ничего не делает, пока на текущем шаге нет хотя бы одной цели.
6. Кликни по строке статуса `autotrading: disabled`. Она станет `autotrading: enabled`, обе кнопки заблокируются. Клик по `autotrading: enabled` выключает маршрут. Переключатель **Выполнять маршрут** в Mod Menu делает то же самое. Персонаж забирает товар, пока в инвентаре не останется одна свободная ячейка, торгует с жителями в сохранённом порядке, складывает результат в выходные контейнеры и снова идёт к входным. Жителя с пустым нужным товаром он пропускает, пока пополнение ещё невозможно даже у загруженного жителя; когда этот срок проходит, проверяет снова. К странствующему торговцу с пустым товаром он больше не идёт. Между кликами выдерживается пауза из настройки.
7. Пока маршрут выполняется, заблокированы движение, прыжок, красться, удар, использование, выброс, инвентарь и хотбар. Чат, клавиша команды, список игроков, скриншот и полный экран остаются. `Esc` открывает меню паузы, и пока маршрут ждёт, статус показывает `autotrading: stop`. Клик по этому статусу выключает маршрут, статус становится `autotrading: disabled`. Смерть тоже выключает маршрут.
8. Если сытости меньше трёх ножек, персонаж ест еду, которая уже лежит в инвентаре, пока шкала не заполнится. Если еды нет, маршрут продолжается. На одной ножке без еды персонаж стоит и ждёт.

Пустой вход или житель без запаса заставляют персонажа ждать. Нет пути, полный выход, пропавшая цель или неверный id предмета дают надпись и звук колокола. В чат мод ничего не пишет и команд не добавляет.

## Настройки

Файл `config/autotrading.json`. Экран открывается через Mod Menu, если стоят Cloth Config и Mod Menu.

| Опция | По умолчанию |
| --- | --- |
| Выполнять маршрут | выкл |
| Показывать панель | вкл |
| Угол панели | `top-right` (`top-left`, `bottom-left`, `bottom-right`) |
| Что забирать | `minecraft:melon` |
| Сделка | 1 `minecraft:melon` за 1 `minecraft:emerald` |
| Вторая цена | пусто |
| Что складывать | `minecraft:emerald` |
| Пауза между действиями | 10 тиков (20 тиков — секунда) |

Сделка сверяется с ценой жителя уже со скидкой, с числом без зачёркивания. Другое количество мод не покупает. Если предложение кончилось, мод ждёт. Пустой вход тоже ждёт. Полные выходы, пропавшая цель, нет пути, смерть и неверный id предмета дают надпись и звук колокола. В чат мод ничего не пишет и команд не добавляет.
