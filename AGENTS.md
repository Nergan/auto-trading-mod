# Auto Trading — инструкции для AI-агентов

Клиентский Fabric-мод только для Minecraft 26.3. Персонаж идёт по маршруту: берёт предметы из входных контейнеров, торгует с выбранными жителями и складывает результат. NeoForge-сборки нет. Modrinth и CDN для этого мода не публикуются: страницы Modrinth нет, новый слот CDN не заводить. Workflow собирает корень на JDK 25 и Gradle `9.7.0` и публикует одну страницу GitHub Release `minecraft-26.3-fabric`.

## Опыт

Если по ходу задачи стало ясно то, что в следующий раз сэкономит неверный ход, допиши это в этот `AGENTS.md`. Ход работы и разовую ошибку не копируй. Неверную старую строку поправь, а не оставляй вторую рядом.

## Правила

- Прежде чем писать своё, портировать или декомпилировать, найди готовый мод, порт или форк. Веб-поиск (Google, Perplexity) малоизвестные репозитории GitHub не видит: репозиторий без звёзд и без ссылки с уже проиндексированной страницы в их индекс не попадает. Ищи каталог GitHub. Перед поиском прочитай https://github.com/aaddrick/gh-cli-search/blob/main/skills/gh-search-repos/SKILL.md и для исходников https://github.com/aaddrick/gh-cli-search/blob/main/skills/gh-search-code/SKILL.md. Нижний порог звёзд не ставь: примеры `stars:>N` в скилле применяй только если владелец просил известные проекты. Скилл https://github.com/py-sit/github-search-skill отбрасывает репозитории без лицензии, без свежих коммитов и учебные, поэтому для порта и малоизвестного мода его не открывай. Сделай несколько запросов: `gh search repos` по имени, `--match readme` и `gh search code` по mod id; для порта добавь `--include-forks true` и список форков исходного репозитория. Дефис в имени совпадает со словами запроса. Минус в начале квалификатора — исключение: такой запрос отделяй `--`, в PowerShell ещё `gh --%`. Пустое описание, ноль звёзд и пустые topics результат не отменяют. Опубликованные моды дополнительно смотри в поиске Modrinth: исходник порта часто есть только на GitHub. Свою реализацию не начинай, пока этот поиск не сделан.
- Код — Kotlin. Новый Java-файл не добавляй. Уже лежащий Java переписывай на Kotlin, когда трогаешь этот мод, не меняя поведение.
- Имя jar: `<mod_id>-<loader>-<minecraft_version>-<mod_version>.jar`. В Prism и в чужую папку модов его не клади. Игрок качает GitHub Release, ту же сборку.
- Issues: чинить только дефект. На каждый issue ответить и закрыть, включая те, где правки нет.
- Коммит и пуш — только когда владелец прямо просит. Для пуша человек запускает `add-commit-push.cmd`. Теги `minecraft-*` двигает workflow релиза.
- Версии в `gradle.properties` не поднимай, пока задача этого не требует. Локальный путь к JDK туда не записывай.

## Готово

Из каталога мода, по порядку. Сеть нужна. Собранный jar человеку для игры не отдавай.

1. Собери проект (`gradlew build --stacktrace`, либо `gradle build --stacktrace`, если wrapper нет).
2. Запусти клиент задачей Gradle и дождись главного меню, затем закрой окно.
3. Запусти локальный сервер и дождись готовности, затем останови его. Клиентский мод тоже не должен ронять сервер.
4. Если клиент или сервер упали, так и напиши. Сборка jar без запуска игры — не конец работы.


## Уроки 26.3

Это клиентский маршрут, не серверный мод. Локальный сервер всё равно должен загрузить мод и не упасть. Порт локального сервера — `25567`. Gradle в workflow пиши `9.7.0`. Путь к локальному JDK в `gradle.properties` не записывай. 26.3 не обфусцирован: зависимости — `implementation`, без `mappings`.

У предмета есть `assets/<mod_id>/items/<id>.json`. Сигнатуры бери `javap` из клиентского jar 26.3. `@Shadow` видит поле только самого целевого класса. Номера кнопок мыши не совпадают с GLFW: `InputConstants.MOUSE_BUTTON_LEFT` равен 1. Проверка `button == 0` левый клик пропускает.

Цикл: набрать товар и оставить одну пустую ячейку, обойти жителей по списку, затем сложить результат. Выбор действия заново после каждого жителя возвращает персонажа к первому жителю и к сундуку. Сундук и результат сделки кладут предметы только в 36 ячеек инвентаря, слоты меню 3–39. Вторая рука туда не входит. Сделку начинай, только когда весь результат и непроданный остаток помещаются в эти 36 ячеек.

Есть нужно через `MultiPlayerGameMode.useItem`, не через `useItemOn`: второй при взгляде на жителя или сундук открывает их экран. Пока персонаж ест, клавишу использования держи нажатой с начала тика. Потеря фокуса через 500 мс открывает паузу и в одиночной игре останавливает тики. Пока маршрут включён, `pauseIfInactive` пропускай. Esc по-прежнему идёт через `pauseGame`.

Пополнение товара жителя клиент не видит: `LastRestock` и `RestocksToday` в клиентской копии остаются нулями. Житель пополняет трейд только в рабочие часы, не больше двух раз за день, и только если чанк тикает. Пропускать жителя можно, лишь пока даже ранний срок не наступил. У странствующего торговца пополнения нет.

Покупка — `setSelectionHint`, `tryMoveItems` и пакет `ServerboundSelectTradePacket`. Без пакета сервер клик по слоту результата отбрасывает. Клик отправляй после паузы, когда `stateId` меню уже сменился.

Полублок — клетка ног. Прыжок только если перепад верха коллизии больше 0.6. На время маршрута выключай `autoJump`. Дверь по пути открывай одним кликом. Две половины большого сундука — один контейнер.

## Craft Anything

[Craft Anything](https://github.com/storytold/craft-anything) — ранняя альфа. Она смотрит, как устроена чужая программа, сайт или игра, и только по отдельной просьбе владельца собирает свою версию. Агенту достаточно `craft-anything-cli`; те же средства отдаёт `craft-anything-cli mcp`. Если команды нет, в середине задачи её не ставить и чужой файл вместо неё не вскрывать.

По умолчанию чистая комната: исходник, файлы и код страницы закрыты. Наружу попадает только видимое: снимок, текст, размеры, цвета, шрифты, открытые меню. Deep включается флагом `--deep` и читает код и файлы своими декодерами, а при установленной Ghidra ещё и ей. Это не песочница системы и не обход защиты, входа или античита. Цель берут только ту, которую владелец имеет право изучать. Логотипы, фотографии и чужой текст в репозиторий не копируют. Запись инструмента — свидетельство с уверенностью и оговорками, не замена нашему коду. Новая сборка по умолчанию уходит в `Documents/Craft Anything`. Править этот репозиторий ею можно только когда владелец просил сборку, с `--project-folder` на каталог репозитория и `--existing edit`. Установка зависимостей выполняет код пакетов; согласие «always allow» для `npm` не давать. Сверка сайта на трёх ширинах уже работает, сверка поведения программ и игр ещё неполная. Статус — `docs/STATUS.md` в том репозитории.

Маршрут торговли уже в этом Fabric-моде 26.3. Чужого жителя и чужой мод торговли не вскрывать. NeoForge-сборку, страницу Modrinth и слот CDN из отчёта инструмента не заводить. Чистая комната уместна, только если владелец просит сверить видимый путь, который можно смотреть.
